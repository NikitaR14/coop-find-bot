# Сверка реализации с ТЗ

Статус: код готов к тестовому внедрению. Продакшен ещё не изменялся.

## Discord и общая база

- [x] Отдельный Discord-процесс и отдельная systemd-служба.
- [x] Та же PostgreSQL-база, что у Telegram-бота.
- [x] Идентификация владельца по паре `platform + user_id`.
- [x] Общая выдача игроков и кланов из Telegram и Discord с отметкой платформы.
- [x] Личные сообщения, приглашения, ответы и заявки между платформами.
- [x] Проверка членства в основном Discord-сервере перед каждой slash-командой.
- [x] Глобальная регистрация команд позволяет приглашать бота на другие серверы.

## Анкета игрока

- [x] Никнейм, Discord Tag, пол, возраст, игры, ранг/уровень, цели, время, описание и фото.
- [x] Пол и возраст необязательны; Discord Tag берётся из Discord автоматически.
- [x] Подтверждение «Все верно?» и выбор публикации анкеты.
- [x] Просмотр, изменение, фото, пауза, возврат в поиск и удаление с подтверждением.
- [x] Фото Telegram-профиля показывается в Discord, локальное Discord-фото — в Telegram.

## Поиск и взаимодействие

- [x] `/search` — поиск по игре, цели и рангу/уровню.
- [x] `/all` — все активные анкеты выбранной игры без фильтров.
- [x] Просмотр общей анкеты, сообщение и приглашение в игру.
- [x] Кнопки возврата в основных разделах и понятные сообщения при пустой выдаче.

## Оценки и опыт

- [x] Через 24 часа после приглашения приходит устойчивое к перезапуску напоминание.
- [x] Варианты «Да», «В процессе», «Нет» работают в Discord и Telegram.
- [x] Три оценки от 1 до 5: вежливость, навык и командная игра.
- [x] Один редактируемый отзыв от игрока на игрока; средние оценки общие для двух платформ.
- [x] +50 за первый/ежедневный вход, +20 за первое сообщение, +10 за новую оценку.
- [x] Не больше трёх наград за оценки в сутки.
- [x] +30 после принятия заявки в клан, +25 за каждый пятый последовательный активный день.

## Кланы

- [x] Создание и поиск кланов для всех игр.
- [x] Название, игра, описание, требования, аватар, сервер и фракция MMO.
- [x] Подтверждение создания; изменение всех полей, смена игры, фото и удаление.
- [x] Заявка лидеру, ответ и отдельное принятие заявки.
- [x] Поиск AION 2 кланов по серверу и фракции в Telegram и Discord.

## AION 2

- [x] AION 2 находится первой в списке игр.
- [x] Анкета игрока: сервер, фракция «Элийцы»/«Асмодиане», ранг/уровень.
- [x] Анкета клана: обязательные сервер и фракция.
- [x] Поля AION 2 отображаются в общей выдаче и участвуют в фильтрах.
- [x] Создание, редактирование и поиск AION 2 добавлены также в Telegram-бот.

## Аналитика

- [x] Отдельный лист Google Sheets `Discord`.
- [x] Discord ID, Discord Tag, активация, заполнение анкеты, старт поиска,
      открытие анкеты, приглашение, переход на сайт и последний вход.
- [x] Заголовки листа создаются автоматически при первой записи.

## Проверки

- [x] Импорт всех Telegram-роутеров и Discord-команд.
- [x] Контракт команд, AION 2, общих моделей, аналитики и трёх кнопок оценки.
- [x] Компиляция всего Python-кода.
- [x] Одна вершина Alembic; SQL миграции успешно генерируется в offline-режиме.
- [x] `poetry check` и проверка критических ошибок Ruff.

Не выполнен только живой smoke-тест с настоящими Discord API, Telegram API,
Google Sheets и производственной PostgreSQL. Он проводится после внедрения по
`deploy/README.md`.
